Používej markdown zápis přímo v textu:

  • Nadpisy: #, ##, ### na začátku řádku
  • Tučné: **text**
  • Kurzíva: _text_
  • Seznam: každý řádek začni -

Klávesové zkratky: Ctrl/Cmd + B pro tučné a Ctrl/Cmd + I pro kurzívu.
